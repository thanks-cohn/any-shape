# Independent understanding before implementation

Any-Shape preserves comprehensible information, authorized operations and trust as form, geometry, resources, input and medium change. Browser resizing is an example, not the mission. Appearance may change; domain identity and essential meaning must survive.

Actors are people, delegated agents, authors, adopters and maintainers. This proof implements only preferences in browser, terminal and newline JSON. Named owner/observer principals are trusted fixture infrastructure, explicitly not production authentication. Desktop, editor/3D and universal platform support remain proposed/unknown.

The stable surface is surface.preferences; its fields are field.display-name and field.density and its mutation is action.apply. A trimmed display name is required, 1–80 characters, transient and never stored in authoritative state or diagnostics. Density is comfortable or compact. State starts revision 0, comfortable. Both channels use one validator and dispatcher, including permission, strict parameters, consent, revision conflicts and actor-scoped retry keys. Accepted identical retries return their original outcome; different reuse fails. Failure never mutates state. Discovery grants no authority.

Mechanisms will be intrinsic wrapping and container-based reflow, native labels/forms/disclosure/navigation, shared state, typed errors, local optional geometry-only diagnostics, and an optional decoration module whose disappearance leaves plain semantic HTML plus a separate terminal renderer. No remote assets are required. State is in-process and resets at restart; durable persistence is outside scope.

The technical policies above are proposed fixture semantics, not newly ratified owner policy. Functional parity, human accessibility, aesthetic quality and historical drop-in compatibility are separate judgments. Unseen CSS/ESM APIs cannot be reproduced honestly: compatibility is UNKNOWN and migration is needed.

Isolation is procedural on a shared filesystem, not enforced by a dedicated machine. I read only supplied neutral documents, canonical semantic projection and universal-v01.json; no original source, history, tests, screenshots, evaluator or parent chat was supplied/read. This file was written before implementation.
