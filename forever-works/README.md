# Any-Shape Continuity Package — Forever Works–inspired profile

**Edition:** 2026-10-15 / profile 0.1 / **status: proposed, source-grounded, partially live-verified**. **Home:** this directory in `thanks-cohn/any-shape`. This is **not** the separate Forever Works standard repository and does **not** supersede the existing `forever/` machine-readable canonical records or vendored standard in `vendor/forever-works/`.

## The rule

**Preserve the software's meaning, permissible operations, causal effects, and human experience; allow implementations to be replaced.** A cold agent must be able to choose a fit-for-purpose language/toolchain without replicating incidental JS, Cloudflare, UI layout, or historical bugs. Any substitution requires independent verification, not confidence from eloquent prose.

## Evidence discipline

Mark each claim **OWNER-INTENT**, **SOURCE-INSPECTED**, **LIVE-OBSERVED**, **TESTED-LOCAL**, **PROPOSED**, **UNKNOWN** or **KNOWN-DEFECT**. These are narrative evidence labels for this profile, not new upstream Forever Works schema enum values. The existing canonical machine records retain their validated schemas/status vocabulary. A green deployment does not establish storage; a D1 record does not establish uploaded bytes; an R2 object does not establish retrieval authorization.

## What the package is / is not

It is an agent-readable *continuity and reconstruction brief* which describes functionality without dictating architecture. It is not a generated code substitute, a perfect specification, proof that three editors work, or permission to weaken access controls. Future conformance MUST compare an independently implemented replacement against explicitly scoped black-box fixtures, declared security constraints, and human experience.

**Change control:** Preserve historical records, append new evidence with dates/IDs, write explicit owner-approved PRESERVE/CORRECT/EXCLUDE decisions, and never promote PROPOSED/UNKNOWN to verified without a traceable test.
