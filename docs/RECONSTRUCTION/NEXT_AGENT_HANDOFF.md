## Reproduce the evidence

```sh
npm ci --ignore-scripts
npm run check:forever
node scripts/evaluate-reconstruction.mjs
PLAYWRIGHT_BROWSERS_PATH="$PWD/.browser-tools/browsers" PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1 npm run check
PLAYWRIGHT_BROWSERS_PATH="$PWD/.browser-tools/browsers" npm run test:recovery
PLAYWRIGHT_BROWSERS_PATH="$PWD/.browser-tools/browsers" npm run test:package
```

Prepare browsers using `docs/DEPENDENCIES.md` if needed; this host's Firefox needs the documented sandbox exception. `check:forever` verifies vendored upstream hashes, invokes its actual CLI validate/audit and runs Ajv against the actual draft-2020-12 schemas. Inspect `valid` and issue counts: the upstream CLI can exit zero despite findings. Proposed capabilities without production implementations legitimately remain audit issues. No vendored upstream code is changed to make the model pass.

Use canonical `explain`, `trace`, `evaluate-replacement` and `verify-migration` from `vendor/forever-works/packages/cli/bin/forever` to inspect the proof's declared replacement scope. Missing claims are unknown; absent CSS/ESM compatibility cannot be inferred from a working Python form. `IMPLEMENTATION_REPORT_002.md` records exact outcomes and any expected failed/partial migration lane.
