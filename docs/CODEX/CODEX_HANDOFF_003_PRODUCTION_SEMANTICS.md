# Future phased handoff: production semantics (proposed)

This is a proposed plan, not an accepted API or implementation. Handoff 002 establishes universal meaning and a scoped reconstruction proof; it does not authorize silently replacing the current browser package.

## Phase 1 — owner/host contract

Select one real adopter/domain and identify essential object/field/action identities, data meanings, host authorization, consent durability, privacy/existence boundaries, revision/merge semantics and acceptable resource targets. Review the unreviewed ontology/fixture proposals. Specify what is accepted and what changes; preserve historical IDs or give migration records. Do not treat proof fixture principal strings as authentication.

## Phase 2 — reusable logical core

Implement a transport-independent validator, state transition boundary, discovery/action schema and host authority adapter. Add complete malformed input, permission, consent, retry, stale/concurrent state and privacy-negative tests. Expose human and agent adapters over the same core. Prove reading and mutation parity rather than merely rendering equivalent labels.

## Phase 3 — second real medium

Choose a genuinely needed text/native/3D/data target with explicit accessibility/resource requirements. Preserve meaning, relationships and feasible operations; represent unsupported aspects honestly. Run all declared positive/negative/transform/fallback probes, human review and real resource benchmarks. Avoid claiming all media from one new adapter.

## Phase 4 — enforced blind trial and migration

Use a different agent/runtime with a technically enforced neutral-input boundary. An independent evaluator retains original machinery and frozen fixture expectations. Separate understanding, reconstruction, accessibility, aesthetics and drop-in compatibility. Complete a real development-driver replacement if claimed. Register canonical evidence/migration/rollback and validate/audit with the pinned or explicitly upgraded actual standard.

## Completion gate

No production promotion until required policies are explicitly accepted, independent evidence covers declared scope, existing web consumers remain protected or migrated, and unknown/manual checks are visible. Version API and model independently. Record actor provenance; a passing proof never upgrades agent-proposed intent by itself.
